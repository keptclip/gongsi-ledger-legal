はじめに

  • 右下の + で記録：金額・日付・相手・カテゴリ・帰属（法人 / オーナー立替）を入力
  • リストは月ごとにグループ化。年別・種別（すべて / 支出のみ / 立替のみ / 主な収入）で絞り込み
  • 行を左スワイプで削除——確認ステップあり
  • 右上のグラフボタンで年度サマリーを表示、CSV レポートを直接出力

よくある質問

データはどこに保存されますか？機種変更時に消えますか？
すべて端末内に保存され、クラウドには送られません。機種変更の前に「設定 → ローカルバックアップ」で JSON を書き出し、新しい端末の「設定 → バックアップを復元」で読み込めば完全に復元できます。月 1 回の書き出しをおすすめします。
「13件を復元しました」と表示されるのに 12件しか見えません
復元されるのはバックアップ内の全年度の記録ですが、リストは選択中の年度のみ表示します。該当する年に切り替えるか「すべて」を選ぶと全件表示されます。データは失われていません。
機種変更後に Pro を再購入する必要がありますか？
不要です。Pro は買い切りです。購入時と同じ Apple ID で、購入ページの「購入を復元」をタップすれば無料で復元できます。
書き出した CSV でそのまま確定申告できますか？
できません。GongSi Ledger はデータ整理ツールであり、税務顧問ではありません。書き出しは整理済みの素材です。正式な申告は公認会計士の確認を受けてください。
言語や通貨記号を変更できますか？
できます。設定ページで簡体字中国語・繁体字中国語・英語・日本語・ドイツ語の 5 言語を切り替えられ、通貨記号も変更可能。切り替えてもデータは変わりません。
削除した記録を復元できますか？
アプリ内の削除は取り消せませんが、変更のたびに自動バックアップが保存されます。「設定 → ローカルバックアップ」で最新のバックアップを確認・復元できます。
アプリはネットに接続しますか？帳簿をアップロードしますか？
接続しません、アップロードもしません。App Store の課金検証を除き、ネットワーク要求は一切行いません。詳しくはプライバシーポリシーをご覧ください。
